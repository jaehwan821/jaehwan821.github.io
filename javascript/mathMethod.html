Math 객체 속성

각 카드의 그래픽은 상수의 크기나 수학적 의미를 한눈에 보여줍니다.

Euler's 상수(E) :

e ≈ 2.71828

자연로그의 밑으로 사용되는 특별한 상수입니다. 증가와 변화율을 계산할 때 자주 등장합니다.

자연로그2 LN2 :

ln(2) ≈ 0.69315

자연로그에서 2를 입력했을 때의 결과입니다. 1보다 작으므로 막대도 낮게 표시됩니다.

자연로그10 LN10 :

ln(10) ≈ 2.30259

자연로그에서 10을 입력한 값이며, 지수와 로그를 연결하는 기준으로 활용됩니다.

2진로그E(LOG2E) :

log₂(e) ≈ 1.4427

자연로그의 밑 e를 2를 밑으로 하는 로그로 바꾼 값입니다.

10진로그E(LOG10E):

log₁₀(e) ≈ 0.4343

e를 10을 밑으로 하는 로그로 표현한 값이며 1보다 작습니다.

PI :

π ≈ 3.14159

원의 둘레를 지름으로 나눈 값입니다. 원과 관련된 계산에 사용됩니다.

SQRT1_2 :

√(1/2) ≈ 0.7071

1을 2로 나눈 값의 제곱근입니다. 1보다 작아 길이가 짧게 표시됩니다.

SQRT2 :

√2 ≈ 1.4142

제곱해서 2가 되는 양의 수입니다. 대각선과 직각삼각형 계산에 자주 사용됩니다.
