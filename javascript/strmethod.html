JAVASCRIPT / STRING

문자열을 읽고
바꾸고 나누는 방법

String은 문자로 이루어진 데이터를 다루는 객체입니다. 아래 예제에서 입력 문자열이 각 메소드에 의해 어떻게 변하는지 확인할 수 있습니다.

01

String 속성

속성은 괄호 없이 사용하며 문자열 자체의 정보나 객체 정보를 확인합니다.

const person = new Human("Kim", "student", 2003);

length문자열의 문자 개수를 반환합니다.
prototype객체가 공유하는 속성과 메소드의 원형입니다.
constructor객체를 만든 생성자 함수를 가리킵니다.
02

문자열 검색과 수정

기준 문자열은 hello, welcome to AI Software!!입니다.

03

문자열 변환과 분리

문자열의 일부를 추출하거나 대소문자와 자료형을 변환합니다.

const text = "Hello, welcome, AI, Software";
text.slice(7, 14);       // welcome
text.split(" ");         // 공백 기준으로 배열 생성
text.toUpperCase();      // 모든 영문자를 대문자로 변환
String 메소드는 원본 문자열을 직접 바꾸지 않고 새로운 값을 반환합니다.
