자바스크립트 삽입 방법

자바스크립트 핵심 정리

  • HTML은 내용, CSS는 디자인/구조, JS는 동작과 반응 담당
  • 넷스케이프의 브렌던 아이크가 개발, ECMAScript 표준 사용
  • 주요 특징: 컴파일 없이 브라우저에서 실행되는 인터프리터 언어

방법 1. 외부 자바스크립트

<head> 내에 <script src="파일경로"></script>를 넣어, src 속성에 외부 JS 파일 경로를 지정하여 불러옵니다.

<script src="예제8-2externjs.js"></script>

방법 2. 내부 자바스크립트 (Head)

<head> 태그 안에서 <script> 태그로 직접 작성합니다.

<script>
  console.log("Head 영역의 내부 자바스크립트가 로드되었습니다.");
</script>

방법 3. 본문 자바스크립트 (Body)

<body> 태그 안쪽에 직접 <script>를 작성합니다. document.write()는 HTML 문서에 텍스트를 출력합니다.

<script>
  document.write("My First JavaScript Using AI (Body 스크립트 출력)");
</script>
