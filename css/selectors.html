01
속성 선택자 (Attribute Selector)
[attr], [attr^=], [attr$=], [attr*=]
CSS2.1 / 3

설명

HTML 요소의 속성값을 기준으로 선택합니다. 값이 특정 문자로 시작(^=), 끝나거나($=), 포함(*=)하는 요소를 정밀하게 타겟팅할 수 있어 클래스 없이도 스타일링이 가능합니다.

  • [href^="https"] — https로 시작
  • [href$=".pdf"] — .pdf로 끝남
  • [href*="github"] — github 포함
  • [type="email"] — 정확히 일치

02
가상 클래스 (Pseudo-class)
:hover, :nth-child(), :first-child, :focus...
CSS3

설명

요소의 상태나 위치를 기반으로 스타일을 적용합니다. 사용자 인터랙션(:hover, :focus)이나 DOM 내 순서(:nth-child, :last-child)를 활용해 JS 없이도 동적인 UI를 구현할 수 있습니다.

  • li:first-child — 첫 번째 자식
  • li:nth-child(2n) — 짝수 번째
  • a:hover — 마우스 오버
  • input:focus — 포커스 상태

03
가상 요소 (Pseudo-element)
::before, ::after, ::first-letter, ::selection
CSS3

설명

HTML을 수정하지 않고 요소의 일부분에 스타일을 추가합니다. ::before/::after로 장식 콘텐츠를 삽입하거나, ::first-letter로 드롭캡 효과를, ::selection으로 텍스트 선택 스타일을 커스터마이징할 수 있습니다.

  • ::before / ::after — 콘텐츠 삽입
  • ::first-letter — 첫 글자
  • ::first-line — 첫 줄
  • ::selection — 선택된 텍스트
live demo
CSS는 웹의 시각적 언어입니다. 선택자를 마스터하면 모든 요소를 자유롭게 스타일링할 수 있습니다.

가상 요소를 활용하면 HTML 마크업 없이 풍부한 타이포그래피 효과를 구현할 수 있습니다. 첫 글자에 자동으로 스타일이 적용됩니다.

04
결합자 (Combinators)
자손(␣), 자식(>), 인접(+), 일반 형제(~)
CSS2 / 3

설명

두 선택자의 DOM 관계를 이용해 타겟을 좁힙니다. 자식 선택자(>)는 직접 자식만, 형제 선택자(~)는 뒤에 오는 모든 형제를, 인접 형제(+)는 바로 다음 형제만 선택합니다.

  • div p — 모든 자손 p
  • div > p — 직접 자식 p만
  • h2 + p — 바로 다음 형제
  • h2 ~ p — 이후 모든 형제

05
논리 선택자 (Logical Selectors)
:is(), :not(), :has(), :where()
CSS4 / Modern

설명

CSS4에서 도입된 강력한 논리 선택자들입니다. :is()로 여러 선택자를 묶고, :not()으로 제외하며, :has()로 자식을 기준으로 부모를 선택하는 "부모 선택자"가 가능해졌습니다.

  • :is(h1, h2, h3) — 그룹 선택
  • :not(.disabled) — 제외
  • div:has(img) — img가 있는 div
  • :where(.nav a) — 명시도 0

06
:root & CSS 커스텀 속성
var(), calc(), :root 전역 변수
CSS3+

설명

:root는 문서 최상위 요소를 선택해 전역 CSS 변수 선언에 사용됩니다. var()로 재사용하고 calc()로 동적 계산을 구현해, 테마 시스템과 반응형 디자인의 핵심 도구가 됩니다.

  • :root { --color: #fff; } — 변수 선언
  • color: var(--color) — 변수 사용
  • width: calc(100% - 2rem) — 계산
  • var(--size, 16px) — 폴백값
