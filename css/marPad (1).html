📦 Margin & Padding

두 속성 모두 여백을 만들지만, 기준이 다릅니다.

margin (외부 여백)
padding (내부 여백)
border
content

Margin — 요소 바깥쪽 여백

border 바깥의 공간. 주변 요소와의 간격을 조절합니다.

margin: 0

margin: 0

margin: 24px

margin: 24px (사방)

margin-right: 32px

margin: 8px 32px 8px 8px

auto

margin: 0 auto (중앙 정렬)

Padding — 요소 안쪽 여백

border 안쪽, content 바깥의 공간. 배경색이 padding 영역까지 채워집니다.

padding: 0

padding: 0

padding: 24px

padding: 24px (사방)

padding-right: 24px

padding: 4px 24px 4px 4px

padding TB

padding: 20px 6px (상하/좌우)
