BORDER

border-style · border-width · border-color · border-radius · border-image

solid border

border-style 01

solid — 실선

가장 기본적인 경계선 스타일입니다. 두께·색상·위치를 자유롭게 지정할 수 있으며 상하좌우 각각 다른 값도 설정 가능합니다.

border: 3px solid #1c1814; border-top: 2px solid red; border-left: 4px solid blue;
dashed
dotted

border-style 02 / 03

dashed — 파선 & dotted — 점선

dashed는 대시(—) 형태의 끊어진 선, dotted는 작은 점으로 이루어진 선입니다. 강조 박스, 드래그 영역, UI 구분선에 자주 활용됩니다.

border: 3px dashed #2d6be4; border: 3px dotted #d94f3d;
double border

border-style 04

double — 이중선

하나의 border로 이중 선 효과를 냅니다. border-width가 최소 3px 이상이어야 두 선이 구분되며, 너비가 클수록 두 선 사이 간격이 넓어집니다.

border: 6px double #2a8c5e; /* width ≥ 3px 필수 */
groove
ridge
inset
outset

border-style 05 ~ 08

groove · ridge · inset · outset — 3D 효과선

브라우저가 밝고 어두운 색을 자동 계산해 입체감을 표현합니다. groove/ridge는 서로 반대, inset/outset도 반대 방향의 3D 효과입니다. 현재는 레트로 UI에서 주로 볼 수 있습니다.

border: 4px groove #888; border: 4px ridge #888; border: 4px inset #6b3fa0; border: 4px outset #c47d15;

border-radius

모서리 둥글기

border-radius로 모서리를 둥글게 만듭니다. 값 하나면 전체, 두 개면 대각선 쌍, 네 개면 top-left부터 시계방향 순서로 적용됩니다. 50%면 원형이 됩니다.

border-radius: 8px; /* 전체 */ border-radius: 8px 0; /* 대각선 */ border-radius: 8px 0 16px 0; /* 각각 */ border-radius: 50%; /* 원 */
그라디언트 테두리
왼쪽 단방향 테두리

border-image / 단방향

그라디언트 테두리 & 단방향 테두리

border-image를 이용하면 그라디언트나 이미지로 테두리를 꾸밀 수 있습니다. 단방향(border-left 등)을 이용하면 콘텐츠 강조선이나 인용구 스타일을 간단히 만들 수 있습니다.

/* 그라디언트 테두리 */ border: 6px solid transparent; border-image: linear-gradient( 135deg, red, blue, green) 1; /* 단방향 */ border-left: 4px solid #d94f3d; border-bottom: 2px solid #2d6be4;
02

MARGIN

요소 바깥 여백 — margin-top / right / bottom / left / auto / 음수

margin-top: 24px margin-bottom: 24px margin-left margin-right
콘텐츠 박스

margin 기초

바깥 여백 구조

margin은 요소와 인접 요소 사이의 바깥 공간입니다. 배경색이 적용되지 않으며 완전히 투명합니다. 파란 점선 영역이 margin 공간, 내부 흰 박스가 실제 요소입니다.

margin: 24px; /* 4면 동일 */ margin: 16px 32px; /* 상하 좌우 */ margin: 10px 20px 30px; /* 상 좌우 하 */ margin: 10px 20px 30px 40px; /* 상 우 하 좌 (시계방향) */
width: 60% + margin: 0 auto

← auto       auto →

margin auto

margin: 0 auto — 수평 중앙 정렬

width가 지정된 블록 요소에 margin: 0 auto를 주면 좌우 여백을 균등하게 나눠 수평 중앙 정렬합니다. Flexbox / Grid 이전 시대부터 쓰인 클래식 레이아웃 기법입니다.

div { width: 60%; margin: 0 auto; /* 수평 중앙 */ }
첫 번째 박스
margin-top: -14px (음수)

negative margin

음수(Negative) 마진

margin에 음수 값을 주면 요소가 정상 흐름을 벗어나 인접 요소 위로 겹칩니다. 중첩 레이아웃, 풀-블리드 이미지, 오버랩 카드 등에 활용합니다. 단, 과용하면 유지보수가 어려워집니다.

/* 위로 14px 올리기 */ margin-top: -14px; /* 좌로 당기기 */ margin-left: -20px;
박스 A — margin-bottom: 20px
박스 B — margin-top: 20px

실제 간격 = 20px (20+20 아님)

margin collapse

마진 겹침(Collapsing)

인접한 블록 요소의 상하 마진은 더 큰 값 하나로 합쳐집니다. 예를 들어 margin-bottom: 20px과 margin-top: 20px이 만나면 20px이 됩니다(40px 아님). Flex/Grid 컨테이너 안에서는 발생하지 않습니다.

/* 겹침 발생 (상하 블록) */ .a { margin-bottom: 20px; } .b { margin-top: 20px; } /* → 실제 간격 20px */ /* 겹침 방지 */ .parent { display: flex; }
03

PADDING

요소 안쪽 여백 — padding-top / right / bottom / left / shorthand

padding-top padding-bottom padding-left padding-right
콘텐츠

padding 기초

안쪽 여백 구조

padding은 요소 테두리(border)와 콘텐츠 사이의 안쪽 공간입니다. 배경색이 padding 영역까지 채워지며, 클릭 영역도 padding만큼 넓어집니다. 초록 영역이 padding 공간입니다.

padding: 28px; /* 4면 동일 */ padding: 16px 32px; /* 상하 좌우 */ padding: 10px 20px 30px; padding: 10px 20px 30px 40px;
padding: 20px
상하좌우 모두 20px
padding: 10px 24px
상하 10 / 좌우 24
padding: 8px 16px 24px
상 8 / 좌우 16 / 하 24
padding: 4px 8px 16px 32px
상/우/하/좌 각각

padding shorthand

단축 속성 4가지 패턴

값의 개수에 따라 적용 방향이 달라집니다. 1개 → 전체, 2개 → 상하/좌우, 3개 → 상/좌우/하, 4개 → 상/우/하/좌(시계방향). margin도 동일한 규칙을 따릅니다.

padding: 20px; padding: 10px 24px; padding: 8px 16px 24px; padding: 4px 8px 16px 32px; /* 시계방향: top right bottom left */
box-sizing: content-box
width = 콘텐츠만 (padding 추가됨)
box-sizing: border-box
width = padding 포함 (권장)

box-sizing

박스 사이징 — content-box vs border-box

box-sizing: content-box(기본)는 width에 padding이 추가돼 실제 크기가 커집니다. border-box는 padding을 포함한 총 크기를 width로 지정해 레이아웃 계산이 직관적입니다. 현대 CSS에서는 border-box를 전역 설정하는 게 표준 관례입니다.

/* 전역 border-box 설정 (권장) */ *, *::before, *::after { box-sizing: border-box; }

CSS Box Model

박스 모델 4겹 구조

모든 HTML 요소는 이 4겹 구조로 이루어집니다.

Content — 실제 텍스트·이미지가 들어가는 영역
Padding — 콘텐츠와 테두리 사이 내부 여백
Border — 요소를 감싸는 테두리선
Margin — 다른 요소와의 외부 여백

/* 전체 구조 예시 */ div { /* content */ width: 200px; height: 100px; /* padding (안쪽) */ padding: 16px 24px; /* border */ border: 2px solid #1c1814; /* margin (바깥쪽) */ margin: 32px auto; }
