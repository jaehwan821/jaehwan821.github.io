📌 position: fixed ← 이 바 자체가 fixed 예제입니다. 스크롤해도 고정됩니다.

📐 CSS Position 5가지

요소의 배치 기준을 결정하는 position 속성을 예제와 함께 비교합니다.

static 기본값 — 문서 흐름대로

모든 요소의 기본값. top / right / bottom / left 속성이 무시됩니다. 위에서 아래로, 왼쪽에서 오른쪽으로 순서대로 배치됩니다.

첫 번째 박스 두 번째 박스 세 번째 박스

코드: position: static; (생략 가능)

relative 원래 위치 기준으로 이동

문서 흐름은 유지하면서 자기 자신의 원래 위치를 기준으로 이동합니다. 원래 자리는 빈 공간으로 남습니다.

일반 박스 relative 박스 (top:12px, left:20px)

코드: position: relative; top: 12px; left: 20px;

absolute 가장 가까운 부모 기준

문서 흐름에서 완전히 제거됩니다. position: relative 이상인 가장 가까운 부모를 기준으로 배치됩니다. 없으면 <html>이 기준.

일반 박스 (흐름) absolute (top:8px, right:8px)

코드: position: absolute; top: 8px; right: 8px; — 파란 부모 기준

fixed 뷰포트(화면) 기준으로 고정

스크롤해도 화면 특정 위치에 고정됩니다. 문서 흐름에서 제거됩니다. 내비게이션 바, 플로팅 버튼에 주로 사용합니다.

☝️ 이 페이지 최상단의 검은 바가 position: fixed로 구현된 예제입니다.
코드: position: fixed; top: 0; left: 0; right: 0;

sticky 스크롤 임계점에서 고정

평소엔 relative처럼 흐르다가, 지정한 임계점(top 등)에 도달하면 fixed처럼 고정됩니다. 아래 박스를 스크롤해보세요.

📊 한눈에 비교

position기준점흐름 유지스크롤 고정주요 용도
static 문서 흐름 ✅ ❌ 기본 배치
relative 자기 원래 위치 ✅ (공간 유지) ❌ 미세 조정, absolute 기준점
absolute 가장 가까운 relative 부모 ❌ ❌ 말풍선, 툴팁, 배지
fixed 뷰포트(브라우저 창) ❌ ✅ 항상 상단 바, 플로팅 버튼
sticky relative → 임계점 후 fixed ✅ ✅ 조건부 테이블 헤더, 섹션 제목
