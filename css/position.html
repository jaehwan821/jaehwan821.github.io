Block  vs  Inline  요소

HTML 레이아웃의 핵심 — 두 가지 디스플레이 유형의 동작 방식을 시각적으로 비교합니다.

Block 요소

display: block
너비
부모 컨테이너의 100%를 자동으로 차지
줄바꿈
요소 앞·뒤로 자동 줄바꿈 발생
크기 조절
width / height 모두 적용 가능
여백
margin · padding 상하좌우 모두 적용

▸ 시각적 데모

div — 전체 너비를 점유합니다
p — 단락 요소, 앞뒤로 줄이 바뀝니다
h2 — 제목 요소, 독립된 줄에 표시됩니다
section — 콘텐츠 구획 요소

▸ 코드 예시

<!-- block 요소는 자동으로 새 줄에서 시작합니다 -->
<div>이 div는 100% 너비를 차지합니다.</div>
<p>다음 줄에 자동으로 배치됩니다.</p>
<h1>제목도 block 요소입니다.</h1>
<ul>
  <li>목록 항목</li>
</ul>

▸ 대표 block 태그

<div> <p> <h1>~<h6> <ul> <ol> <li> <section> <article> <header> <footer> <nav> <form> <table> <blockquote>

Inline 요소

display: inline
너비
콘텐츠 크기만큼만 차지 — 줄 안에 나란히 배치
줄바꿈
줄바꿈 없이 텍스트 흐름 속에 위치
크기 조절
width / height 적용 불가
여백
좌우 margin·padding만 적용, 상하는 레이아웃에 영향 없음

▸ 시각적 데모

일반 텍스트 사이에 <span>스팬 이 인라인으로 삽입되고, <a>링크 도 줄 안에 있으며, <strong>굵은 글자 와 <em>기울임 도 모두 같은 줄에 나란히 흐릅니다. 텍스트가 길어지면 자연스럽게 다음 줄로 이어집니다. <code>코드 도 인라인입니다.

▸ 코드 예시

<!-- inline 요소는 텍스트 흐름 안에 배치됩니다 -->
<p>
  이 문장에서 <span style="color:orange">이 부분</span>만 강조됩니다.
  <a href="#">링크</a>도 같은 줄에 있고,
  <strong>굵게</strong>나 <em>기울임</em>도 마찬가지입니다.
</p>

▸ 대표 inline 태그

<span> <a> <strong> <em> <b> <i> <code> <img> <input> <button> <label> <abbr> <sup> <sub>

📊 한눈에 비교

속성 Block 요소 Inline 요소
기본 너비 부모의 100% 콘텐츠 너비만큼
줄바꿈 자동 줄바꿈 줄바꿈 없음
width / height ✅ 적용 가능 ❌ 적용 불가
margin (상하) ✅ 적용됨 ❌ 레이아웃에 영향 없음
padding (상하) ✅ 적용됨 ⚠️ 시각적으로만 적용
중첩 규칙 block·inline 모두 포함 가능 inline 요소만 포함 가능
주요 용도 레이아웃 구조, 섹션 구분 텍스트 강조, 링크, 아이콘
혼합 방법 display: inline-block — 두 속성의 장점을 결합 (너비 지정 가능 + 줄 안에 배치)
